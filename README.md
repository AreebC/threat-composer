# Threat Composer - AWS ECS Deployment

## Overview
A production-style AWS infrastructure project for deploying a containerised Threat Composer application using 
Terraform, Amazon ECS Fargate, Amazon ECR, Application Load Balancer, Route 53 and AWS Certificate Manager (ACM).
The project focuses on Infrastructure as Code, container orchestration, networking, secure HTTPS access and automated deployment practices.
